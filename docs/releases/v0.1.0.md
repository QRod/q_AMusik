# q_AMusik v0.1.0 · Primera versión

Reproductor de escritorio nativo para Ubuntu/Zorin, con biblioteca local GTK y
GStreamer. Esta es una entrega inicial: la suscripción de Apple Music se abre
en el navegador oficial; el catálogo todavía no está integrado en esta interfaz.

## Incluye

- Importación de canciones y carpetas, metadatos, búsqueda y SQLite local.
- Favoritos y listas locales; pausa, posición, volumen, anterior/siguiente,
  aleatorio y repetición.
- Paquete `q-amusik_0.1.0_all.deb`, sumas `SHA256SUMS`, licencia MIT y guía en español.

## Instalar en Ubuntu / Zorin

Descarga el `.deb` y `SHA256SUMS` adjuntos en la misma carpeta:

```sh
sha256sum -c SHA256SUMS
sudo apt update
sudo apt install ./q-amusik_0.1.0_all.deb
q-amusik
```

Continúa si la comprobación muestra `OK`.
[Guía completa de instalación y desinstalación](https://github.com/QRod/q_AMusik/blob/v0.1.0/docs/INSTALACION.md).

## Alcance

Las listas locales no se sincronizan con Apple. No incluye descargas offline
del servicio, Dolby Atmos, AirPlay ni paridad con la aplicación de macOS.
Las pruebas automatizadas usan audio sintético y una salida de prueba, sin
dispositivo físico. Zorin, el audio físico, Apple ID, suscripción y DRM necesitan
comprobación en un equipo real.
