# q_AMusik v0.2.0 · Nueva biblioteca visual

Interfaz nativa rediseñada con Impeccable, tomando Music de macOS como referencia:
carátulas, navegación compacta y controles de reproducción superiores.

## Novedades

- Claro y oscuro siguiendo las preferencias del escritorio.
- Cuadrículas de álbumes y artistas, detalle de colección y tabla de canciones.
- Carátulas incrustadas en MP3/FLAC/M4A o archivos cover/folder JPG y PNG locales.
- Selección visible, iconos simbólicos y estados vacíos y búsqueda mejorados.

La biblioteca, favoritos y listas de v0.1.0 se conservan sin migración.

## Instalar o actualizar en Ubuntu / Zorin

Descarga `q-amusik_0.2.0_all.deb` y `SHA256SUMS` en la misma carpeta:

```sh
sha256sum -c SHA256SUMS
sudo apt update
sudo apt install ./q-amusik_0.2.0_all.deb
q-amusik
```

Continúa si la suma muestra `OK`. APT instala la dependencia gráfica Cairo
adicional junto con GTK/GStreamer.

[Guía de instalación](https://github.com/QRod/q_AMusik/blob/v0.2.0/docs/INSTALACION.md)

## Alcance

La suscripción de Apple Music sigue abriéndose en el navegador oficial. Los
controles, favoritos y listas de esta aplicación corresponden a la biblioteca
local. No se añaden descargas offline del catálogo, Dolby Atmos ni AirPlay.

Las capturas usan canciones silenciosas y carátulas geométricas de demostración;
esos datos no se instalan en la biblioteca del usuario.
