# q_AMusik v0.3.0 · Apple Music dentro de la aplicación

Versión preliminar: el reproductor oficial se abre **dentro de q_AMusik**, sin
lanzar Chrome/Firefox y sin requerir Apple Developer Program. La biblioteca
local, favoritos y listas se conservan.

## Instalar o actualizar

Cierra q_AMusik, descarga el `.deb` y `SHA256SUMS` en la misma carpeta:

```sh
sha256sum -c SHA256SUMS
sudo apt update
sudo apt install ./q-amusik_0.3.0_all.deb
q-amusik
```

Continúa si la suma muestra `OK`.
[Guía completa](https://github.com/QRod/q_AMusik/blob/v0.3.0/docs/INSTALACION.md).

## Escuchar tu suscripción

Pulsa **Escuchar** en la barra lateral e inicia sesión en el reproductor que
aparece dentro de la ventana. Usa una cuenta con Apple Music activo.

La reproducción completa necesita Widevine compatible. Qt puede usar el CDM de
Google Chrome instalado en Linux; Chrome no necesita estar abierto. Ese módulo
no está incluido ni se descarga automáticamente. El botón **Requisitos** explica
los pasos. En Wayland se necesita XWayland para alojar la biblioteca GTK.

## Verificado y pendiente

Las pruebas usan audio sintético para verificar reproducción web/local, pausa al
cambiar de fuente, ventanas internas y cierre limpio. También cargan la página
pública real de Apple sin cuenta. Esto no demuestra que una suscripción vaya a
reproducir canciones completas en todas las combinaciones de sistema y CDM.

**Pendiente en tu equipo:** inicio de sesión, segundo factor, canción completa,
audio físico y compatibilidad concreta de Zorin. No se promete paridad con macOS,
descargas offline del catálogo, Dolby Atmos o AirPlay.

La sesión de Apple se guarda en un perfil propio privado; no se leen perfiles de
tus navegadores ni se extraen contraseñas o tokens hacia el código nativo.
